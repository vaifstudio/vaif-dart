# Security policy

## Reporting a vulnerability

Report security vulnerabilities in this SDK privately by email to
security@vaif.studio. Do not open a GitHub issue, pull request or discussion
for a vulnerability; those are public.

Include as much of the following as you can:

- the affected version of `vaif_client` (or the commit), the Dart or Flutter
  version, and the platform (Android, iOS, macOS, Windows, Linux, web or
  server);
- a description of the issue and its impact, for example which credentials,
  tokens or data it exposes;
- the steps or a minimal program that reproduces it;
- any logs or captured requests, with credentials, tokens and personal data
  removed.

Vulnerabilities in the VAIF Studio service itself, rather than in this SDK,
go to the same address.

## What happens next

We confirm that we received your report, investigate it, and keep you informed
of our progress. When a fix is ready, we release it and publish an advisory
for this repository. We credit you in the advisory unless you ask us not to.

We do not take legal action against good-faith research that stays away from
other people's data and gives us time to fix the issue before it is made
public.

## Supported versions

Security fixes are released for the latest minor version of the current major
version.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier than 1.0 | No (never released) |
